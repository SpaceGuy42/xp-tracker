# 🎮 XP Tracker CLI

A simple command-line XP tracker built in C. Designed to help users simulate RPG-style progress by logging completed tasks and calculating experience points.

---

## ⚙️ Features

- ⌨️ Command-line input interface
- 🔁 Infinite loop logic with `while(1)`
- 🚪 Exit logic using `break`
- 💡 XP calculation: 10 XP per task
- 🧙🏾‍♂️ Character naming system (v1.1+)

---

## 🛠️ How to Run

### Prerequisites
- `gcc` installed (via MinGW or equivalent)
- Terminal or Git Bash
- Windows OS (for `.exe`) — cross-platform adaptable

### Compile
```bash
gcc xp_tracker.c -o xp_tracker.exe

# Run
./xp_tracker.exe
